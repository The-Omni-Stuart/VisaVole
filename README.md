# Visa Vole

Visa Vole is an Android app for checking travel access based on the passports, visas, and residence permits you hold. Add your documents, then explore an interactive world map showing where you can travel visa-free, on arrival, or with a visa requirement.

Visa Vole uses [VisaDB](https://github.com/The-Omni-Stuart/VisaDB) as its bundled visa-rule dataset.

## Features

- Map and Documents tabs
- Add, edit, and remove travel documents
- Color-coded world map based on your documents
- Country detail view with access rules
- Bundled local SQLite visa data and simplified world geometry

## Requirements

- Android Studio
- Android API 28 or newer
- A JDK compatible with the project’s Android Gradle Plugin

## Build

From the repository root:

```bash
./gradlew :app:assembleDebug
```

The build automatically fetches the latest [VisaDB](https://github.com/The-Omni-Stuart/VisaDB) release and refreshes the bundled database when its SHA-256 changes.

Install the debug APK:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Tests

```bash
./gradlew :app:testDebugUnitTest
```

## Map geometry

The map asset lives at:

```text
app/src/main/assets/world_robinson.bin
```

It is generated by:

```bash
python3 tools/gen_robinson2.py
```

The generator expects the project’s local shapefile data and Python geometry dependencies to be available.
